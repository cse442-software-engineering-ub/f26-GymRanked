# Exercise backup photos

Photos for the exercise guide's fallback (`src/GuideFallback.jsx`), shown when the WorkoutX demo clip is missing or fails. Each is the first photo of the matching exercise in the [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), which is released under the [Unlicense](https://unlicense.org/) (public domain; credit isn't required but is listed here). The files are unchanged copies. The written steps in `src/exerciseBackupSteps.json` are from the same dataset.

Some matches are the closest movement the dataset has, not an exact one (for example Bulgarian split squat uses Split Squats, A-skip uses Fast Skipping, hip hinge uses Good Morning, pike push-up uses Push-Ups With Feet Elevated and bird dog uses Superman). Swap in a better photo for any of them by changing its entry in `src/exerciseBackupSteps.json` and this table.
